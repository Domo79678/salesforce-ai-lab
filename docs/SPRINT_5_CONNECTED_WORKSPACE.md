# Sprint 5: Connected Administration Workspace

## Outcome

Sprint 5 connects deterministic recommendations to the workspaces where an
administrator can investigate or continue the task. It also adds a dashboard
task center and a guided pre-build planning workflow. No AI capability is used.

## Recommendation-to-Workspace Routing

`recommendationWorkspaceService` is the shared recommendation navigation
boundary. It:

- honors an explicitly registered destination;
- otherwise maps recommendation category or metadata type to routing hints in
  `copilotModuleRegistry`;
- falls back to Org Health when the recommendation has no more specific
  supported destination; and
- emits the existing `workspacenavigate` event consumed by
  `copilotWorkspaceRouter`.

New destinations are registered in `copilotModuleRegistry`. Recommendation
cards must not implement their own category-to-workspace maps.

## Admin Task Center

`adminTaskCenter` is a reusable dashboard section. It uses the shared cached
metadata snapshot and `orgKnowledgeService`; it does not introduce a metadata
collector or a parallel analysis engine.

The section displays:

- high-priority recommendations generated by deterministic analysis;
- other recommended actions;
- registry-derived quick launches; and
- a Recent Activity placeholder that explicitly waits for a verified
  change-history source.

Empty, loading, and unavailable states do not substitute simulated data.

## Ask Before You Build

`askBeforeYouBuild` is a guided workspace for Object, Field, Flow, Validation
Rule, Permission Set, Report, and Dashboard changes. The user supplies:

1. change type;
2. business problem; and
3. affected user groups.

`preBuildGuidanceService` returns a deterministic feature framing, consultant
considerations, a testing checklist, and related registered workspaces. The
guidance is a planning aid, not an assertion that the selected feature is
correct for every requirement. Flow and Validation Rule plans route to the
existing Automation Advisor when deeper solution-pattern evaluation is needed.

The workspace performs no metadata retrieval and makes no org-specific impact,
security, deployment-readiness, or dependency claims.

## Verification

Focused Jest tests cover:

- deterministic guidance contracts;
- registry-backed destination resolution;
- Admin Task Center recommendation rendering and navigation;
- Ask Before You Build validation, output, and related-workspace navigation; and
- Workspace Router forwarding.

Representative-org validation is still required before treating mappings or
guidance as production-ready.
