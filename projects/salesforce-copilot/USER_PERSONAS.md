# User Personas

## Persona 1 — New Salesforce Admin ⭐

Experience:
0–2 Years

Needs:

- Learn Salesforce
- Understand Flows
- Explain automation
- Build confidence

Pain Points:

- Overwhelmed
- Poor documentation
- Unsure where automation starts

---

## Persona 2 — Solo Admin ⭐⭐⭐⭐⭐

Experience:
2–5 Years

Needs:

- Save time
- Troubleshoot quickly
- Generate documentation
- Improve automation

Pain Points:

- Too much work
- No backup
- Constant interruptions

---

## Persona 3 — Consultant ⭐⭐⭐⭐

Needs:

- Understand client orgs quickly
- Analyze automation
- Produce documentation
- Identify improvements

---

## Persona 4 — Business Analyst

Needs:

- Understand business processes
- Explain requirements
- Document changes
- Create user stories
